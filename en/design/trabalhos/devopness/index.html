From MVP to a PRODUCT with 12+ features in production

2023—2019

bh/mg

mission

Entre 2019 e 2023, fui co-fundador e líder de Design da startup Devopness, com a mission de transformar as práticas de DevOps em uma experiência simples e escalável.

problem

O problem era duplo: automatizar operações técnicas de DevOps e, ao mesmo tempo, construir uma base de Design System escalável em nível global.

learnings

  • Creating UI patterns from the start reduces technical debt;
  • CRUD patterns are effective for maintaining UX consistency;
  • Agile methods without technical review don't guarantee quality;
  • OKRs give the company clearer, more precise direction;
  • Documentation is essential for global scale;
  • If it isn't documented, it doesn't exist;
  • Open source accelerates building.

challenge

How might we turn DevOps operations into an intuitive UX while building a Design System at startup speed?

results

12+ features developed and launched;

30+ tests conducted with beta users;

90% Design System adoption since launch.

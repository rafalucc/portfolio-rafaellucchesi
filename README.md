# Portfolio Rafael Lucchesi

Site pessoal (arte e design) de Rafael Lucchesi — feito em HTML/CSS estático, baseado no design do Figma.

🔗 **Site no ar:** https://rafaellucchesi.com

## Estrutura

- `index.html` — Home
- `arte/` — seção de arte (trabalhos, exposições, sobre, obras disponíveis)
- `design/` — seção de design (trabalhos, blog, sobre)
- `assets/` — CSS, imagens, fontes e JS usados em todas as páginas

## Como editar

Cada página é um `index.html` dentro da pasta correspondente. Para editar:
1. Abra o arquivo da página desejada
2. Edite o texto/HTML diretamente
3. Faça commit das alterações

## Deploy

O site é publicado automaticamente via GitHub Pages a cada push na branch `main`.

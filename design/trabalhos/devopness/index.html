devopness

Do MVP a um SaaS com +12 features em produção

2023 — 2019

bh/mg

missão

Entre 2019 e 2023, fui co-fundador e líder de Design da startup Devopness, com a missão de transformar as práticas de DevOps em uma experiência simples e escalável.

problema

O problema era duplo: automatizar operações técnicas de DevOps e, ao mesmo tempo, construir uma base de Design System escalável em nível global.

aprendizados

  • Criar padrões UI desde o início reduz débito técnico;
  • Padrões CRUD são eficientes para manter consistência UX;
  • Métodos ágeis sem revisão técnica não garantem qualidade;
  • OKRs direcionam a empresa com mais clareza e precisão;
  • Documentações são fundamentais para escala global;
  • Se não está documentado, não existe;
  • Open source acelera a construção.

desafio

Como podemos transformar operações de DevOps em uma UX intuitiva e, ao mesmo tempo, construir um Design System no ritmo acelerado de uma startup?

resultados

+12 features desenvolvidas e lançadas;

+30 testes realizados com usuários beta;

90% de adoção do Design System desde o lançamento.
